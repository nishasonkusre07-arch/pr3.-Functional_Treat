# 📊 Functional Treat – Data Analyzer & Transformer

## 🌟 Project Overview

**Functional Treat** is a Python-based menu-driven application designed to perform various data analysis and transformation tasks. It allows users to work with both **1D** and **2D arrays** while demonstrating important programming concepts such as functions, recursion, lambda expressions, filtering, sorting, and statistical analysis.

This project is beginner-friendly and helps understand how different Python functions work together to build a complete application.

---

# 🎯 Project Objectives

- 📥 Accept user input for 1D and 2D datasets
- 📋 Display complete data summary
- 🧮 Calculate factorial using recursion
- 🔍 Filter data using Lambda Function
- 📊 Sort data in ascending or descending order
- 📈 Generate dataset statistics
- 🎓 Demonstrate Python functional programming concepts
